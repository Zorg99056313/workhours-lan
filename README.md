# 研发工时统计系统 · 局域网版 v1.4

**用考勤管理员的个人电脑当服务器**，用于小型科技公司应对税务加计扣除合规性检查，通过简单的方法做出最真实的工时原始记录，让稽查无话可说。内网访问，不依赖任何云服务、不需要公网 IP、不需要 IT 部门开虚机。
数据全部留在本机 `data` 目录里。

### 第 4 条说清楚：什么是"填报周期"

以前按自然周（周一~周日）填。问题是：**某月 28 日是周日时，29/30/31 是周一到周三，属于下一周**——按自然周填就要把 11 月的日子一起填，月底结账还得等。

现在系统按月切分周期：

```
2024-01（28 日是周日）
  周期1  01-01 ~ 01-07   7 天   应填 10
  周期2  01-08 ~ 01-14   7 天   应填 10
  周期3  01-15 ~ 01-21   7 天   应填 10
  周期4  01-22 ~ 01-31  10 天   应填 16   ← 29/30/31 并进来了，表格多 3 行
```

打开 `样例\2024年1月研发工时统计表（跨周示例）.xlsx` 和 `界面预览_工时填报.png` 能直接看到效果。

**规则可调**（`app/config.py`）：

```python
PERIOD_TAIL_MERGE_DAYS = 3   # 月末零碎天数 ≤ 该值 → 并入上一个周期
PERIOD_HEAD_MERGE_DAYS = 3   # 月初零碎天数 ≤ 该值 → 并入下一个周期
```

调大（如 4）会让更多零碎天并入相邻周期，表格更长、周期更少；调成 0 就退化成纯自然周。

### 工资月怎么改

月度跨度默认是「上月 26 日 ~ 当月 25 日」。想改起始日（例如改成 1 号，即自然月）：

```python
# app/config.py
MONTH_CYCLE_START_DAY = 26   # 改成 1 就是自然月（1日~月末）
```

改完重新启动即可，**历史数据会自动按新口径重算**归属月份和周期（只重算一次，之后不会反复动）。
改起始日不会丢数据，只是每条记录重新归月。

### 填报周期到底怎么切（月首/月末不是周一、周日时）

工资月固定是「上 M-1 月 26 日 ~ 本月 25 日」，起点几乎不可能正好是周一、终点也很少正好是周日。
系统的切法是：**在工资月范围内按自然周（周一~周日）切片，首尾不满一周的零碎天按天数决定是否并入相邻周期**。

| 首片段（26 日 → 该周周日） | 处理 |
|---|---|
| 26 日是周一 → 正好 7 天 | 不合并，就是完整一周 |
| 26 日是周二/三/四 → 6/5/4 天 | >3 天，**单独成一个短周期** |
| 26 日是周五/六/日 → 3/2/1 天 | ≤3 天，**并入下一周**，首期变成 10/9/8 天 |

| 末片段（该周周一 → 25 日） | 处理 |
|---|---|
| 25 日是周日 → 正好 7 天 | 不合并 |
| 25 日是周四/五/六 → 4/5/6 天 | >3 天，**单独成一个短周期** |
| 25 日是周一/二/三 → 1/2/3 天 | ≤3 天，**并入上一周**，末期变成 8/9/10 天 |

实测 2024-01 ~ 2030-12 共 84 个工资月（355 个周期）：

- 每个月的周期数：**4 个**（55 个月）或 **5 个**（29 个月）
- 周期长度：7 天 221 个、10 天 26 个、4 天 25 个、6 天 24 个、5 天 23 个、9 天 23 个、8 天 23 个
- 首尾对齐、连续、不重叠、天数之和 = 工资月天数：**84 个月全部通过**
- 不存在 0 个工作日的周期，最长为 10 天

也就是说：**"一周" 并不总是 7 天**，月首/月末那两期会是 4~6 天的短周期，或者被并成 8~10 天。
`PERIOD_TAIL_MERGE_DAYS` / `PERIOD_HEAD_MERGE_DAYS` 可以调（调大 → 更少但更长的周期；调 0 → 纯自然周切片，短周期更多）。

## 二、装起来只要 1 步（约 1 分钟）

### 用安装包（推荐，给不懂电脑的同事）

双击 **`研发工时统计系统_安装包_v1.4.exe`** → 点「开始安装」→ 装完点「启动程序」。

安装包已经**自带 Python 运行环境**，目标电脑不需要装 Python、不用 pip、不用联网。

默认安装到 `D:\研发工时统计系统`（没有 D 盘就装到用户目录）。安装时会：
- 创建桌面 + 开始菜单快捷方式
- 在「程序和功能」里注册卸载入口
- 问你要不要放行防火墙（需要一次管理员授权）和开机自启

**覆盖安装会保留历史数据**（`data`/`输出`/`备份` 三个目录不覆盖），升级直接再跑一遍安装包即可。

### 绿色版（免安装）

解压 **`研发工时统计系统_绿色版_v1.4.zip`** 到任意可写目录，双击里面的 `WorkHours.exe` 即可，
同样自带运行时。删掉文件夹就等于卸载（先备份 `data`）。

### 给 IT 批量静默部署

```
研发工时统计系统_安装包_v1.4.exe /S /D=D:\研发工时统计系统 /FIREWALL=1 /DESKTOP=1 /AUTOSTART=0
```

参数：`/S` 静默、`/D=` 安装目录、`/FIREWALL=` 放行防火墙、`/DESKTOP=` 建桌面快捷方式、`/AUTOSTART=` 开机自启。
`/FIREWALL=1` 会弹一次 UAC（或整体以管理员身份运行则无需弹窗）。日志写在 `%TEMP%\whs_install.log`。

### 不用安装包的绿色方式

解压后直接双击 **`WorkHours.exe`** 即可，所有文件都在自己文件夹里，删掉文件夹就等于卸载。

> 想看命令行窗口的启动过程，仍是双击 `启动服务.bat`（纯 ASCII，中文提示由 `launcher.py` 打印）。

然后把 `http://你的内网IP:8000` 发到部门群。
